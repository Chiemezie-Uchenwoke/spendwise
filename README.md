# 💰 SpendWise – Expense Tracker

SpendWise is a modern and secure expense tracking web application that helps users manage their personal finances with ease. Users can log, edit, and delete daily expenses, filter expenses by date and category, and gain insights into their spending habits over time.

## Features

- User authentication with **JWT**, **Bcrypt**, and **Express-session**
- Add, edit, and delete income / expenses
- Filter entries by **date** and **category**
- Secure backend APIs built with **Node.js** and **Express**
- Responsive UI using **React** and **Tailwind CSS**
- File uploads using **Multer** 
- Environmental configurations with **Dotenv**
- MongoDB database for storing users, incomes and expenses
